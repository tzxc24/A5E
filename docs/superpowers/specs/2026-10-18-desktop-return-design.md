验证：临时运行目录第一次不跳过、第二次跳过；服务保留运行目录且停止时保持图形模式；ARM 编译并验证游戏退出后的实际参数、服务状态和启动编号。显示模式切换仍可能短暂黑屏，不能承诺无缝切换。
